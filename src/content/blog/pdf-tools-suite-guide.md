# What Is the PDF Tools Suite?

The **PDF Tools Suite** is a growing set of free, client‑side utilities that let you manipulate PDF files directly in your browser. Because all processing happens locally, you never have to upload sensitive documents to an external server.

# Available Tools (and What’s Coming)

- **PDF Merger** – Combine two or more PDF files into one document (available now).
- **PDF Splitter** – Extract specific pages or divide a document into multiple files (planned).
- **PDF Compressor** – Reduce file size by optimizing images and removing unused objects (planned).
- **PDF Page Rearranger** – Drag‑and‑drop to reorder, rotate, or delete pages (planned).
- **PDF to Image Converter** – Export pages as PNG or JPEG (planned).
- **Encryption & Decryption** – Add or remove password protection (planned).

# Why Choose an Offline PDF Suite?

1. **Total privacy**: Your files stay on your device.
2. **No ads or tracking**: Pure utility without third‑party scripts.
3. **Works offline**: Once loaded, the tools continue to function without an internet connection.
4. **Instant results**: No upload/download delays.
5. **Cross‑platform**: Use on any modern browser — desktop or mobile.

# Best Practices for Working with PDFs Offline

- **Validate before processing**: Confirm that PDFs are not corrupted or password‑protected (unless you have the password).
- **Keep backups**: Although the tools are non‑destructive, it’s wise to retain originals until you’re satisfied with the result.
- **Check output quality**: Especially for compression, ensure that images and text remain acceptable.
- **Stay updated**: Refresh the page occasionally to get the latest features and security improvements.
